I model one of the seven Meta-Geopolitical capacities defined by Al-Rodhan (2014, 2018) for assessing state power. My capacityType is one of: socialHealth, domesticPolitics, economics, environment, scienceHumanPotential, militarySecurity, or internationalDiplomacy. I hold a normalized score (0.0-10.0), a trend (improving, stable, worsening, critical), quantitative indicators as a dictionary, a validity period, supporting evidence, and free-text notes. Key methods include isCritical (score < 3), isStrong (score > 7), and addIndicator:value: for populating quantitative metrics. I am part of the State Typology Enrichment and Meta-Geopolitical Capacity Model (Phase 5).
