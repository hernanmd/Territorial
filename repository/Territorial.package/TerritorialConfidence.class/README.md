I am an attachable confidence annotation for any TerritorialNamedObject, implementing the OTTAOA.1 validation layer (Phase 8). I hold a truthValue (true, false, uncertain, misleading, or unverified), a confidenceScore (0.0 to 1.0), the assessing TerritorialAgent, an assessmentDate, the sourceArtifact (TerritorialInformationArtifact), and free-text reasoning. Key methods include isReliable (score > 0.8), isUnreliable (score < 0.5), and confidenceCategory categorization. I enable intelligence analysts to mark information as uncertain, disputed, or false, which is critical for territorial claim validation.
