I contain example script methods implementing the five case studies from the Territorial Enhancement Plan. Each method constructs a live object model that can be inspected and explored:\n\n- kurilIslandsDispute: Creates the basic Russia-Japan sovereignty dispute model (Case Study 1)\n- kurilIslandsClaimsWithDetails: Extends the dispute with claims, argument types, and confidence levels\n- kurilIslandsTreatiesAndConfidence: Full model with treaties, information artifacts, motives, and confidence assessments\n- norwayStateProfile: Al-Rodhan Meta-Geopolitical profile for Norway across 7 capacities (Case Study 2)\n- somaliaStateProfile: Al-Rodhan Meta-Geopolitical profile for Somalia showing capacity imbalance\n- amalfiCoastLandscape: Cataldo-Rinaldi cultural landscape with denotative/connotative signs (Case Study 3)\n- constantinopleToIstanbul: HHT temporal versioning with disruptive/non-disruptive changes (Case Study 4)\n- middleEarth: Tolkien fictional world with countries, routes, leaders, and the War of the Ring dispute (Case Study 5)\n\nAll methods return the root object of the constructed model for further inspection. Execute any method via: TerritorialCaseStudyExamples new middleEarth
