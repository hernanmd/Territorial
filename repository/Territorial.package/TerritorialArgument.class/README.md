I structure the reasoned defense of a territorial claim as an information content entity. I hold a collection of premises (TerritorialInformationArtifact instances), a conclusion (the TerritorialClaim being argued), an argument type, a validity period, whether the evidence is preponderant (strong vs weak), and reference URLs with scores. I support amendment over time via amendWith: to track how arguments evolve. I am part of the Territorial Disputes and Claims Layer (Phase 1) based on the OTTAOA.1 framework.
