I represent an explicit change between two TerritorialVersion instances, following the HHT-Change taxonomy. I inherit territory, startDate, endDate from TerritorialEventMarker and add a changeType (appearance, disappearance, nameChange, geometryChange, attributeChange), before and after version references, and an isDisruptive flag indicating whether the change affects the territory identity. Constantinople becoming Istanbul is a nameChange that is NOT disruptive (identity preserved); the 1453 conquest IS disruptive. I am part of the Temporal Versioning and Change Taxonomy (Phase 3).
