I represent a fluents-inspired versioning of a TerritorialObject across time, following the HHT (Historical Hierarchical Territory) ontology. I hold a territory reference, a validity period (TerritorialTimeMarker), a state snapshot dictionary of properties, and whether this version is deprecated. Two versions can be compared via diffFrom: to compute property changes. I work together with TerritorialChange and TerritorialAnnexation to model identity-preserving vs. disruptive territorial transformations. I am part of the Temporal Versioning and Change Taxonomy (Phase 3).
