I represent a state as a legal entity with defined territory, population, government, and the capacity to engage in international relations. A state is distinct from a country: all states are countries but not all countries are states. I inherit from TerritorialArea to gain spatial capabilities (centroid, area, neighbours). I hold a reference to my corresponding TerritorialCountry and optionally a TerritorialStateProfile with capacity assessments. My subclasses model state typologies: TerritorialFailedState, TerritorialRogueState, and TerritorialPariahState.
