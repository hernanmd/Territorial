I model a territorial dispute between two or more parties over a specific territory. I track claimants, the disputed territory, the state of the dispute (active, dormant, resolved, or frozen), the dispute type (border, sovereignty, resource, strategic, cultural, or historical), the intensity level (diplomatic, tension, skirmish, conflict, or war), the claims made by each party, any involved third parties, and associated treaties. I am part of the Territorial Disputes and Claims Layer (Phase 1) based on the OTTAOA.1 framework by Donohue, Otte, and Smith (2014).
