I model biological diversity and resources per the 1992 UN Convention on Biological Diversity. I hold speciesDiversity as a taxon-to-population dictionary, ecosystemDiversity as a collection of symbols, geneticDiversity as a population-to-variance dictionary, threatenedSpecies as a collection of species names, and protectedAreas as a collection of TerritorialProtectedArea references. Key methods include diversityIndex and endemismScore. I am part of the Territorial Planning and Cultural Landscape Ontology (Phase 9).
