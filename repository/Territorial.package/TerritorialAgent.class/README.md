I am the abstract root for any entity that can act in a territorial context. I hold an agentType (government, organization, militia, liberationMovement, internationalBody, ngo, religiousBody, corporation, or individual), a validity period, roles, and memberships. I am part of the Actor and Agent Model (Phase 2) based on the HHT ontology and OTTAOA.1 framework. My subclasses include TerritorialPerson for individual actors.
