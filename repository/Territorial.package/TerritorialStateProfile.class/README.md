I aggregate all seven Meta-Geopolitical capacities (Al-Rodhan 2014, 2018) into a comprehensive state power profile for a TerritorialState. I hold a dictionary mapping capacity type symbols to TerritorialStateCapacity instances and an assessment period. Key methods include overallScore (weighted average), weakestCapacity and strongestCapacity (extremes), capacityImbalance (detecting variance indicating overspending in one domain at the expense of others), and stabilityAssessment (critical, warning, or stable). I am part of the State Typology Enrichment and Meta-Geopolitical Capacity Model (Phase 5).
