I implement the semiotic distinction from Cataldo and Rinaldi (2010) between denotative and connotative meaning for territorial elements. I hold a signifier (the physical form), a denotativeMeaning (what the object IS - its function), a connotativeMeaning (what the object REPRESENTS - its symbolic/ideological significance), and an interpretiveContext (historical, aesthetic, ecological, functional, perceptive, or cultural). I am part of the Territorial Planning and Cultural Landscape Ontology (Phase 9).
