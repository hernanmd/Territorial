I represent a composite change involving multiple territories such as merges, splits, redistributions, and annexations. I inherit from TerritorialChange and hold a collection of subChanges (TerritorialChange instances) and a patternType (split, merge, redistribution, annexation, secession). My isContinuation flag distinguishes identity-preserving continuations from identity-creating derivations per the HHT ontology. For simple annexations, prefer using TerritorialAnnexation directly. I am part of the Temporal Versioning and Change Taxonomy (Phase 3).
